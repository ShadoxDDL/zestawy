# Auto kalendarz SI

Natywny dodatek do panelu dodatków Gargonem. Automatycznie otwiera kalendarz eventowy i odbiera nagrodę przypisaną do bieżącej daty.

Plik dodatku na GitHub Pages:

`https://shadoxddl.github.io/autokalendarz/Auto-kalendarz-SI.js`

## Publikacja

1. Wgraj trzy pliki z paczki do głównego katalogu repozytorium `ShadoxDDL/autokalendarz`.
2. W **Settings → Pages** wybierz **Deploy from a branch**, gałąź `main` i katalog `/(root)`.
3. Po publikacji zainstaluj `Auto-kalendarz-SI-loader.user.js` w Tampermonkey.

Dodatek nie posiada osobnego okna. Włącza się i wyłącza go standardowo w panelu dodatków Gargonem.
