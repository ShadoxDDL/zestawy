# Auto zmiana zestawów – własna kopia

Repozytorium przechowuje lokalną kopię dodatku `Auto-zmiana-zestawow.js`.

Adres pliku na GitHub Pages:

`https://shadoxddl.github.io/zestawy/Auto-zmiana-zestawow.js`

## Instalacja

1. Wgraj trzy rozpakowane pliki do głównego katalogu repozytorium.
2. Upewnij się, że GitHub Pages publikuje gałąź `main` z katalogu `/(root)`.
3. Zainstaluj `Auto-zmiana-zestawow-loader.user.js` w Tampermonkey.

Kopia nie aktualizuje się automatycznie z serwera pierwotnego autora.
