# Zmieniacz zestawów – własna kopia

Repozytorium przechowuje lokalną kopię dodatku `Zmieniacz-zestawow.js`.

Adres pliku na GitHub Pages:

`https://shadoxddl.github.io/autoxgarg/Zmieniacz-zestawow.js`

## Instalacja

1. Wgraj trzy rozpakowane pliki do głównego katalogu repozytorium.
2. Upewnij się, że GitHub Pages publikuje gałąź `main` z katalogu `/(root)`.
3. Zainstaluj `Zmieniacz-zestawow-loader.user.js` w Tampermonkey.

Kopia nie aktualizuje się automatycznie z serwera pierwotnego autora.
